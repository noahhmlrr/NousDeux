# NousDeux

## 1. Installer sur les iPhone/android
Ouvrir le lien dans **Safari** > Partager > **Sur l'écran d'accueil**. Chacun choisit « Il » ou « Elle », entre le prénom à afficher dans l'espace privé, puis crée l'espace ou rejoint avec le code de l'autre. Les notifications push sur iPhone nécessitent iOS 16.4 ou plus récent et l’app lancée depuis son icône sur l’écran d’accueil. Sur chaque iPhone, appuie sur **Activer les notifications** et accepte la demande iOS.
